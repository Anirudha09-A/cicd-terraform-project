Version 1

Deployed automatically with GitHub Actions

Every push to this repository is tested, copied to an Azure VM, and served by Nginx. No manual steps.

1. Push

Commit your change to the main branch on GitHub.

2. Test

The workflow checks that the required files and tags exist.

3. Deploy

Files are copied to the VM over SSH and Nginx is reloaded.

Built with GitHub Actions, Azure VM and Nginx
